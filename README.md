# Muscleup4you – Corporate (statische Website)
1. Neues GitHub-Repository anlegen und alle Dateien hochladen (Ordnerstruktur beibehalten).
2. Settings > Pages > Source: "Deploy from a branch", Branch `main`, Ordner `/ (root)`.
3. Unter "Custom domain" `corporate.muscleupforyou.com` eintragen und "Enforce HTTPS" aktivieren.
4. DNS beim Domain-Anbieter: Typ CNAME, Name `corporate`, Ziel `<dein-github-benutzername>.github.io`.
5. Kontaktformular: auf web3forms.com mit muscleupforyou@gmail.com einen kostenlosen Access Key anfordern und in `index.html` `DEIN_WEB3FORMS_KEY` ersetzen. Die E-Mail-Adresse steht dann nicht im Quelltext.
6. Platzhalter in `impressum.html` ausfüllen.
